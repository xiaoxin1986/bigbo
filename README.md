# BigBo

一个用**纯 HTML + CSS + JavaScript** 实现的极简动态时间线应用。打开页面，写下此刻的想法，内容会立刻出现在时间线顶部，并保存在浏览器本地，刷新或下次打开依然还在。

无需安装、无需构建、无需联网，双击 `index.html` 即可使用。

## 预览

```
┌──────────────────────────────────────────┐
│  B  BigBo                [ 本地存储 ]    │
│     记录此刻，分享所想                   │
├──────────────────────────────────────────┤
│  ⬤  此刻在想什么？                       │
│     ───────────────────  0 / 280  [发布] │
├──────────────────────────────────────────┤
│  最新动态                          3 条  │
│  ┌────────────────────────────────────┐  │
│  │ ⬤ BigBo 用户 · 2 分钟前            │  │
│  │   今天把 BigBo 跑起来了             │  │
│  └────────────────────────────────────┘  │
└──────────────────────────────────────────┘
```

## 功能

| 功能 | 说明 |
| --- | --- |
| 发布动态 | 输入文字后点击「发布」或按 `Ctrl / ⌘ + Enter`，内容立即出现在时间线顶部 |
| 时间线查看 | 按发布时间**倒序**展示全部动态，包含头像、作者、相对时间与正文 |
| 本地持久化 | 所有数据以 JSON 形式存放在浏览器 `localStorage`，刷新、关闭重开都不丢失 |
| 输入校验 | 空白内容不可发布；实时字数统计，上限 280 字，接近上限变橙、超限变红 |
| 空状态引导 | 没有动态时展示引导页，可一键聚焦到输入框 |
| 交互反馈 | 发布成功 / 失败均有底部 Toast 提示；新卡片带入场动画 |
| 响应式 | 桌面端 640px 居中单列，移动端自动切换为全宽卡片布局 |

## 技术栈

- **HTML5**：语义化结构（`header` / `main` / `section` / `ol` / `time`），可访问性标注（`label`、`aria-live`、`role="status"`）
- **CSS3**：CSS 变量设计令牌、渐变、玻璃拟态、`@keyframes` 动效、`prefers-reduced-motion` 降级、媒体查询响应式
- **原生 JavaScript（ES2020）**：IIFE 隔离作用域，无任何框架与第三方依赖
- **Local Storage**：单一版本化 key 存储，读写全程异常兜底

> 项目刻意不使用框架、构建工具、CDN 与外部字体图标，确保在完全离线的环境下通过 `file://` 协议直接打开也能完整运行。

## 运行方式

1. 克隆或下载本仓库到本地；
2. 用浏览器直接打开 `index.html`（双击即可，无需本地服务器）。

如需通过本地服务器访问，也可以任选一种：

```bash
python -m http.server 8000     # 然后访问 http://localhost:8000
npx serve .                    # 需要本机已安装 Node.js
```

## 目录结构

```
bigbo/
├── index.html    # 页面结构：品牌栏、发布区、时间线、空状态、Toast
├── styles.css    # 全部视觉样式与响应式规则
├── app.js        # 应用逻辑：Storage / Utils / Render / Controller 四层
├── README.md     # 项目说明
└── .gitignore    # 忽略本地编辑器与系统产物
```

`app.js` 内部按职责分区，数据单向流动：

```
用户操作 → Controller 校验 → Storage 写入 localStorage
                              ↓
        DOM 更新 ← Render 全量重绘 ← 最新数据列表
```

## 数据结构

`localStorage` key：`bigbo.posts.v1`

```json
[
  {
    "id": "b3f1c8a2-4d7e-4a91-9c3f-0a6b2e5d7f10",
    "content": "今天把 BigBo 跑起来了",
    "createdAt": 1763001600000
  }
]
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 唯一标识，优先使用 `crypto.randomUUID()`，不支持时以时间戳 + 随机数兜底 |
| `content` | string | 纯文本正文，渲染时只通过 `textContent` 写入 |
| `createdAt` | number | 创建时间毫秒时间戳，用于倒序排序与相对时间显示 |

读取时会对 JSON 解析失败、非数组、字段缺失等情况做过滤与降级，损坏数据不会阻塞页面；写入时若遇隐私模式或存储配额异常，会以 Toast 明确提示，而不是静默丢失内容。

## 安全说明

- 所有用户内容一律使用 `textContent` 写入 DOM，不拼接 `innerHTML`，从根源避免脚本注入；
- 不使用 `eval`、`new Function` 等动态执行手段；
- 不发起任何网络请求，数据始终留在本机浏览器中。

## 浏览器兼容

支持所有现代常青浏览器（Chrome / Edge / Firefox / Safari 近两年版本）。相对时间显示使用标准 `Intl` 之外的轻量实现，不依赖额外 API 兼容层。
